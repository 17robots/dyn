# Lexical Elements

## Identifiers
Identifiers are sequences of characters with the purpose of being used as variable names
Identifiers can include numbers, letters, and underscores, but the identifier cannot start with a number
Lowercase letters and uppercase letters are different from one another so "Variable" and "variable" are different identifiers.

## Keywords
Keywords are identifiers that are designated for use by Dyn, so they cannot be used as other identifiers

## Constants
A const is a literal character or number like 'a' or 1. 
All constant values are given a type like other variables.
The value assigned to the constant cannot change and must be calculatable at compile time
