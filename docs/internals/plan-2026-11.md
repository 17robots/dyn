# Cleanup plan, 2026-11-16

Each step lands as its own commits with the full suite passing. Every language
change updates the C compiler, the self-host parser, tests, `language.md`, the
editor grammars, std and the examples.

1. **Language removals:** labeled loops, `for *const`, `#load`, `#instance`, `#offset`,
   `#offsetof` (after `TypeMember.offset`), `#max`/`#min`, integer-range
   exhaustiveness, panic unwinding through caller frames.
2. **Language additions and rules:** `#step`, target-typed arithmetic, signed/unsigned
   comparison, `x % n` narrowing, generic inference with ordinary conversions,
   readable generic names; then remove the casts vet reports as redundant.
3. **Overflow checks cover std:** drop the SDK exemption, use `math.wrapping_*`
   where wrapping is meant, run everything with `--check-overflow`.
4. **Rules doc:** `docs/guide/rules.md`, one numbered list; costs move to `costs.md`.
5. **Error model:** sticky failure on the object with operation and path; remove
   `io.Result`, `io.Transfer`, `{value, failure}` results; `process.spawn` returns a value.
6. **Arenas:** about eight functions, out-of-memory panics, a block source,
   `std/mem` free of `std/observe`.
7. **Layers:** core / heap / std with a riscv64-none CI check.
8. **Sweeps:** `usize` for public counts and sizes; run-time `assert`.
9. **HTTP:** handlers return nothing, `respond(response, body)`, automatic 500 and
   `already responded`, `too_large`/`busy` handlers, `query_has`, direct cookies,
   more HTTP/3 tests.
10. **Tooling:** fix-it hints, a `fix` field in JSON diagnostics, `dyn guide --brief`,
    an evaluation corpus.
11. **Speed:** benchmarks against Zig; pass unmodified large parameters by pointer.
12. **Finish:** port examples and DNA, editor grammars, changelog and migration
    guide, freeze, release.
