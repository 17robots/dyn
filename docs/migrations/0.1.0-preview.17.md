# Migrating to Dyn 0.1.0-preview.17

Preview 17 is compatible with preview 16. Upgrade the complete SDK so the
compiler, standard library, runtime and language server stay together.
If upgrading from preview 15 or earlier, first apply the
[preview 16 allocation migration](0.1.0-preview.16.md).

## Standard streams in older applications

Import `std/io` and replace `terminal.stdin()`, `terminal.stdout()` and
`terminal.stderr()` with `io.stdin()`, `io.stdout()` and `io.stderr()`.
Keep `std/terminal` only for terminal-specific functions such as raw mode,
attachment detection and key decoding. Standard streams support redirected
pipes and files; they do not require a terminal.

```dyn
use "std/io"
fn main() {
  result := io.println(io.stdout(), "Hello from Dyn")
  if result.status == io.Status.Error { #panic("output failed") }
}
```

On WASI, `std/io` and `std/os/wasi` can now be imported together. Continue
using their public slice APIs; applications do not need the shared raw bindings.
No allocation failure policy or error-handling convention changes in this release.

## Arena ownership transfer

When moving an arena descriptor into longer-lived state, use
`arena = mem.arena_take(&created.arena)` instead of `arena = created.arena`.
This clears the source descriptor. The destination owns release/reset afterward.
Construct allocator handles after the owner reaches its final location: moving
an arena does not retarget handles that already point to its old descriptor.

## Debug builds

A compiler fix removes invalid debug metadata on hoisted stack storage. No
source workaround is needed. Rebuild affected applications with `--no-cache`.
