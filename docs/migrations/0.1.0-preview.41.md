# Upgrading to preview 41

Preview 41 ships the next-design redesign: unified `<T>` generics, return-value error handling (`T!E`, `try`, `catch`, `fail`, `errdefer`), `nocopy struct` ownership with `#take`, cleaner syntax (significant newlines, `.len`, alias-first `use`, raw backtick strings, `.Variant` shorthand, labeled loops), and native release optimization improvements.

Every removed form produces a compiler error pointing to the new spelling.

## 1. Upgrade the compiler and editors together

Pin `0.1.0-preview.41` in `mise.toml`, update `tree-sitter-dyn` (now pure `grammar.js` with `src/scanner.c` removed) and `dyn-editors`, and restart `dyn lsp`.

## 2. Syntax cleanups

- **Imports:** put the alias before the path and drop `as`:
  ```dyn
  // Before
  use "std/fs" as files

  // After
  use files "std/fs"
  ```
- **Length:** replace `#len(xs)` with `xs.len` on slices and fixed arrays.
- **Strings:** `str` is the spelling for `[]const u8`. Multi-line raw strings use backticks (`` `...` ``).
- **Floats:** require a digit after the dot (`2.0` instead of `2.`).
- **Headers:** parenthesize struct literals inside `if`, `for`, or `case` headers (`if p == (Point{ x: 1 }) { ... }`).
- **Newlines:** newlines end statements outside `(...)` and `[...]` and after `,`, `{`, or binary operators.
- **Enum shorthand:** `.Variant` works wherever one concrete enum type is expected.
- **Labeled loops:** `outer: for ...` with `break outer` / `continue outer` is supported again.

## 3. Generics (`<T>`) and `case T`

Replace `$T`, `T: type`, `Box(T)`, and `#instance(f, T)` with `<T>`:

```dyn
// Before
struct Box(T: type) { value: T }
fn push(T: type, arena: *mem.Arena) *T { ... }
node := mem.push(Node, arena)
hash := #instance(key_hash, u32)

// After
struct Box<T> { value: T }
fn push<T>(arena: *mem.Arena) *T { ... }
node := mem.push<Node>(arena)
hash := key_hash<u32>
```

Inside a generic function, `case T { str => ... _ => ... }` dispatches on type at instantiation time.

## 4. Error handling (`T!E`) replaces `std/fail`

`std/fail` and `*fail.Status` parameters are removed. Fallible functions return `T!E`, `!E`, `T!`, or `!`, where `E` is an enum or an enum union (`A | B`):

```dyn
// Before
status: fail.Status
text := fs.read_all(arena, &status, "app.json", 1 << 20)
if status.failed {
  io.eprintln("app: {}", fail.describe(storage[..], status.failure))
  return
}

// After
text := fs.read_all(arena, "app.json", 1 << 20) catch err {
  io.eprintln("app: {}", err)
  return
}
```

- Use `try expr` to propagate errors to a caller whose return error type covers them.
- Use `catch fallback` for defaults (e.g., `header(req, "x-tag") catch ""`).
- Use `errdefer cleanup()` for rollback that runs only when returning via `fail`.
- `std/io`, `std/fs`, `std/net`, `std/process`, and vendor wrappers return `T!io.IoErr`; parsers and decoders return `T!parse.ParseErr`; core primitives fail with bare `!`.
- `io.text(err)` or `{}` formatting describes errors directly.

## 5. `nocopy struct` and `#take`

Owners such as `mem.Arena` are `nocopy struct` types and cannot be implicitly copied. Use `#take(&value)` to transfer ownership explicitly.

## 6. Enum payloads and `any` patterns

Enum payloads are declared as `Variant(T)` and matched as `Variant(name) =>` or `Variant(*name) =>` (where `*name` is a pointer). Variant 0 may carry a payload. Type patterns on `any` use `i32(n) =>`.

## 7. `evented.Config.large_body`

Replace `config.on_large_body = upload` with `config.large_body = evented.large_bodies(upload)`.
