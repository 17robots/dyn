# Migrating to Dyn 0.1.0-preview.19

Preview 19 adds type parameters to functions (see
[the generics design](../generics-design.md)) and makes allocation arena-only.
`Allocator`, `#allocator`, `#AllocResult`, `AllocError` and the eight `#alloc*`
builtins are removed, along with `TypeKind.AllocationHandle` and
`TypeKind.AllocationResult`. Upgrade the complete SDK so the compiler, standard
library, runtime and language server stay together.

## Typed allocation

Pass the arena itself instead of an `Allocator` made from it.

| Preview 18 | Preview 19 |
| --- | --- |
| `#alloc_or_panic(T, mem.arena_allocator(&arena))` | `mem.push(T, &arena)` |
| `#alloc_slice_or_panic(T, mem.arena_allocator(&arena), n)` | `mem.push_array(T, &arena, n)` |
| `#alloc_slice_uninit_or_panic(u8, mem.arena_allocator(&arena), n)` | `mem.push_bytes_uninit(&arena, n)` |
| `#alloc_uninit_or_panic(T, ...)`, `#alloc_slice_uninit_or_panic(T, ...)` | `mem.push(T, &arena)`, `mem.push_array(T, &arena, n)` (zeroed) |
| `#alloc(T, ...)`, `#alloc_slice(T, ...)` (recoverable) | `mem.arena_push` / `mem.arena_push_array`, then check `.ok` and cast `.memory` |
| `mem.growing_allocator(&growing)` | `mem.growing_push*` on the growing arena |

`mem.push`, `mem.push_array` and `mem.push_bytes_uninit` panic when the arena is
full. Uninitialized typed storage is only available through the byte-level
`mem.arena_push_uninit`; cast its memory when zeroing a large value measurably
matters.

## std output functions

| Preview 18 | Preview 19 |
| --- | --- |
| `strings.clone_alloc(output, s)` | `strings.clone(&arena, s)` |
| `strings.join_alloc(output, parts, sep)` | `strings.join(&arena, parts, sep)` |
| `ini.parse(output, source)` | `ini.parse(&arena, source)` |

`strings.Result.allocation_error` and `ini.ParseResult.allocation_error` are
removed. A full arena reports `strings.ErrorKind.Capacity` or
`ini.ErrorKind.Capacity` (formerly `Allocation`).

## Arena pushes

The byte-level `mem.arena_push*` functions remain. The typed helpers remove the
casts around them:

```dyn
node := mem.push(Node, &arena)                     // was #cast(*Node) mem.arena_push_or_panic(&arena, #sizeof(Node), #alignof(Node))
items := mem.push_array(Item, &arena, count)       // zeroed []Item
bytes := mem.push_bytes_uninit(&arena, size)       // was (#cast(*u8) mem.arena_push_uninit_or_panic(&arena, size, 1))[..size]
```

## Arenas from the OS cannot fail

`arena_create` reserves address space and panics when the OS refuses, so it
returns the arena directly. Release, frames, sub-arenas, pools and free lists
follow. Pages cost memory only when pushes reach them (Windows now commits on
demand too), so reserve generously.

| Before | After |
| --- | --- |
| `created := mem.arena_create(n)` + `if !created.ok {...}` + `&created.arena` | `arena := mem.arena_create(n)` + `&arena` |
| `_ = mem.arena_release(&a)`, `mem.arena_release(&a).ok` | `mem.arena_release(&a)` |
| `mem.frames_create(n)` returning `FramesResult` | returns `Frames`; `frames_release` returns nothing |
| `arena_sub_or_panic`, `pool_init_or_panic`, `free_list_from_arena_or_panic` | `arena_sub`, `pool_init`, `free_list_from_arena` (panic on failure) |
| `growing_release(&g).ok`, `growing_trim(&g, n).ok` | `growing_release(&g)`, `growing_trim(&g, n)` |

`ArenaResult`, `FramesResult`, `PoolResult`, `FreeListResult` and `mem.Status`
are removed. Pushes into a fixed arena still report a full arena through
`arena_push`, or panic through `mem.push`.

## Generic helpers

- `mem.copy`, `mem.move`, `mem.zero` and `mem.fill` accept any slice type.
  Existing `[]u8` calls keep working. `mem.swap` and `mem.equal` are new.
- `mem.clear(value)` zeroes the value behind a pointer and replaces byte
  casts such as `mem.zero((#cast(*u8) state)[..#sizeof(State)])`.
- `math.min`, `math.max`, `math.clamp` and `math.abs` replace `min_i64`,
  `max_i64`, `min_u64`, `max_u64`, `clamp_i64` and `abs_i64`.
  `math.narrow(T, value)` converts and panics if the value does not fit.
- `sort.sort` and `sort.search` replace `sort.i64s`, `sort.u64s`,
  `sort.search_i64` and `sort.search_u64`, and accept any type that
  supports `<`.
- New `std/slice`: `reverse`, `index_of` and `contains`.
- New `strings.format(arena, template, ...)`, `strings.List` with
  `list_push`, `list_push_format` and `list_join`, and `mem.Frames`
  (`frames_create`, `frame_current`, `frame_previous`, `frame_advance`,
  `frames_release`). See [memory patterns](../memory-patterns.md).

## Several imports in one use

`use` accepts a comma-separated list. Each item takes an optional alias, as
before:

```dyn
use "std/mem" mem, "std/strings", "std/io" out
```

Existing one-import `use` lines are unchanged. Editor highlight queries must
match `(import ...)` inside `(use ...)`; update editor packages together with
the grammar.

## Compile-time assertions

`#assert(condition)` and `#assert(condition, "message")` are new top-level
declarations. The condition must be a compile-time `bool`: integer literals,
constants, `#sizeof`, `#alignof`, `#offsetof`, arithmetic, comparisons, `!`, `&&` and `||`.
A false condition is a compile error that includes the message.

```dyn
packed struct Header { tag: u32, size: u64 }
#assert(#sizeof(Header) == 12, "Header is written to disk")
#assert(#offsetof(Header, size) == 4)
```

`#offsetof(Struct, field)` is the field's byte offset as a `usize`, usable in
any expression.

## Embedded files

`#load("path")` embeds a file's bytes as a `[]const u8` at compile time:

```dyn
const ICON: []const u8 = #load("assets/icon.png")
```

The path is relative to the file containing `#load` and may not contain `..`,
so a module only embeds files in its own directory tree. Builds and the
analysis cache notice edits to loaded files. The language server does not
reanalyze when only a loaded file changes; edit or save the source to refresh.
