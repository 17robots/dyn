# Migrating to Dyn 0.1.0-preview.19

Preview 19 adds type parameters to functions (see
[the generics design](../generics-design.md)) and makes allocation arena-only.
`Allocator`, `#allocator`, `#AllocResult`, `AllocError` and the eight `#alloc*`
builtins are removed, along with `TypeKind.AllocationHandle` and
`TypeKind.AllocationResult`. Upgrade the complete SDK so the compiler, standard
library, runtime and language server stay together.

## Typed allocation

Pass the arena itself instead of an `Allocator` made from it.

| Preview 18 | Preview 19 |
| --- | --- |
| `#alloc_or_panic(T, mem.arena_allocator(&arena))` | `mem.push(T, &arena)` |
| `#alloc_slice_or_panic(T, mem.arena_allocator(&arena), n)` | `mem.push_array(T, &arena, n)` |
| `#alloc_slice_uninit_or_panic(u8, mem.arena_allocator(&arena), n)` | `mem.push_bytes_uninit(&arena, n)` |
| `#alloc_uninit_or_panic(T, ...)`, `#alloc_slice_uninit_or_panic(T, ...)` | `mem.push(T, &arena)`, `mem.push_array(T, &arena, n)` (zeroed) |
| `#alloc(T, ...)`, `#alloc_slice(T, ...)` (recoverable) | `mem.arena_push` / `mem.arena_push_array`, then check `.ok` and cast `.memory` |
| `mem.growing_allocator(&growing)` | `mem.growing_push*` on the growing arena |

`mem.push`, `mem.push_array` and `mem.push_bytes_uninit` panic when the arena is
full. Uninitialized typed storage is only available through the byte-level
`mem.arena_push_uninit`; cast its memory when zeroing a large value measurably
matters.

## std output functions

| Preview 18 | Preview 19 |
| --- | --- |
| `strings.clone_alloc(output, s)` | `strings.clone(&arena, s)` |
| `strings.join_alloc(output, parts, sep)` | `strings.join(&arena, parts, sep)` |
| `ini.parse(output, source)` | `ini.parse(&arena, source)` |

`strings.Result.allocation_error` and `ini.ParseResult.allocation_error` are
removed. A full arena reports `strings.ErrorKind.Capacity` or
`ini.ErrorKind.Capacity` (formerly `Allocation`).

## Arena pushes

The byte-level `mem.arena_push*` functions remain. The typed helpers remove the
casts around them:

```dyn
node := mem.push(Node, &arena)                     // was #cast(*Node) mem.arena_push_or_panic(&arena, #sizeof(Node), #alignof(Node))
items := mem.push_array(Item, &arena, count)       // zeroed []Item
bytes := mem.push_bytes_uninit(&arena, size)       // was (#cast(*u8) mem.arena_push_uninit_or_panic(&arena, size, 1))[..size]
```

## Generic helpers

- `mem.copy`, `mem.move`, `mem.zero` and `mem.fill` accept any slice type.
  Existing `[]u8` calls keep working. `mem.swap` and `mem.equal` are new.
- `math.min`, `math.max`, `math.clamp` and `math.abs` replace `min_i64`,
  `max_i64`, `min_u64`, `max_u64`, `clamp_i64` and `abs_i64`.
  `math.narrow(T, value)` converts and panics if the value does not fit.
- `sort.sort` and `sort.search` replace `sort.i64s`, `sort.u64s`,
  `sort.search_i64` and `sort.search_u64`, and accept any type that
  supports `<`.
- New `std/slice`: `reverse`, `index_of` and `contains`.
