# Upgrading to preview 40

Preview 40 has the last breaking changes before the freeze:

- one failure model, `fail.Status`, for every std and vendor call
- a smaller arena API
- one HTTP server and router
- the 2026-11-16 language cleanup

Most changes are mechanical. Work through them in this order.

## 1. Upgrade the compiler and the editors together

Pin the new SDK, and update the editor adapters to the dyn-editors release
that pins preview 40. The Tree-sitter grammar no longer parses loop labels, `for *const` or
`#offset`, and it does parse `#wrapping`, `#step`, the float builtins and bare
blocks. Restart `dyn lsp`.

## 2. Run `dyn fix`

```sh
dyn fix .
```

`dyn fix` applies every certain fix, repeats until none is left, then
checks. It covers:

- Same-argument renames, such as `mem.push_bytes_uninit` to `mem.push_bytes`
  and `mem.arena_remaining` to `mem.arena_room`.
- `for *const` to `for *`.
- Habits from other languages, such as `let`, `while` and `x++`.

For about 100 other removed functions, `dyn check` names the replacement
but cannot rewrite the call, because the arguments change. The rest of this
guide covers those, grouped by area. The editor shows the same hints and
fixes as quick fixes.

## 3. Failures: pass a `fail.Status`

Results with a `failure` field are gone: `io.Failure`, `io.Result`,
`io.Transfer`, `fs.Result`, `parse.Result`, `http.Result` and the per-module
`*Result` types. A call that can fail now takes a `*fail.Status` and returns
its value. The first failure stays in the status, and later calls given a
failed status do nothing and return zero or empty. So you check once, before
you use the results:

```dyn
// Before
loaded := fs.read_all(arena, "app.json", 1 << 20)
if io.failed(loaded.failure) {
  io.eprintln("app: {}", io.describe(storage[..], loaded.failure))
  return
}
use_config(loaded.value)

// After
status: fail.Status
text := fs.read_all(arena, &status, "app.json", 1 << 20)
if status.failed {
  io.eprintln("app: {}", fail.describe(storage[..], status.failure))
  return
}
use_config(text)
```

The rules, for every std and vendor call:

1. If it can fail, it takes the status, and returns zero or empty after a
   failure.
2. A lookup always returns a usable value: zero or empty when it is not
   there, with `NotFound` on the status. Read an optional value with a
   status of its own.
3. An iterator returns its value too, and sets `ended` on its state when it
   has nothing left (see "Iterators" below).
4. Check `status.failed` before you use what you got.

Argument order:

- The status comes first: `fs.open(&status, path)`.
- When the call allocates, the arena comes before the status:
  `fs.read_all(arena, &status, path, maximum)`.
- Cleanup functions such as `fs.close`, `fs.unmap`, `sqlite.finalize` and
  the destroy functions take no status, so they work after a failure.

Read an optional value with its own status, so a missing one stops nothing
else. To react to one kind of failure, give that step its own status and look
at `failure.kind`:

```dyn
opened: fail.Status
file := fs.open(&opened, path)
if opened.failed && opened.failure.kind == fail.Kind.NotFound {
  // create it
}
```

| Before | After |
| --- | --- |
| `io.failed(x.failure)` | `status.failed` |
| `io.describe(storage, failure)` | `fail.describe(storage, status.failure)` |
| `io.Kind` | `fail.Kind` (the same values) |
| `io.write_all(writer, bytes)` | `io.write(&status, writer, bytes)` (writes everything) |
| `io.println_to(writer, ...)` returning a `Transfer` | `io.println_to(&status, writer, ...)` |
| `parse.malformed`, `parse.failed_at` | `fail.at(&status, kind, operation, message, offset)` |
| `time.sleep(d).failure` | `time.sleep(d)` (returns nothing) |
| `time.deadline_expired(&d).value` | `time.deadline_expired(&d)` (a `bool`) |
| `x.valid == false` for bad input (`time.parse_iso8601`, `path.safe_join`, `big.to_u64`, ...) | a failure on the status |
| `json.get(T, value, key)` / `json.as(T, value)`: zero, `""` or `nil_value` when missing or the wrong kind | `json.get(T, &status, value, key)` returns the plain value; missing or null records `NotFound` (`"port" is missing`), the wrong kind or out of `T`'s range `InvalidInput` |
| `ini.find(source, section, key)`: `""` when absent or malformed | `ini.find(&status, source, section, key)`: `""` with `NotFound`, or `InvalidInput` for malformed text |
| `http.header`, `request_header`, `param`, `cookie`, `cookie_in`, `form_field` returning `{name, value, found}` | Each takes `&status` and returns the value; a missing one records `NotFound` |
| `http.query_value` / `form_value` returning `{value, found}` | The decoded bytes; missing records `NotFound`, bad encoding `InvalidInput` |
| `process.environment(arena, &status, name)` returning `{value, found}` | The value; unset records `NotFound`. `process.environment_or(arena, name, fallback)` is unchanged |
| `linux.environment_get(&status, name, destination)` returning `{value, found}` | The value; unset records `NotFound` |
| `regex.find(program, text)` returning `Found{ value, captures }` | `regex.find(&status, program, text)` returning `Match{ start, end, captures }`; no match records `NotFound`. A capture is a `Span`; one that took no part is `Span{}` |
| `sessions.cached(...)`, `sessions.remember(...)` with `session.found` | Both take `&status` first: `cached` records `NotFound` on a miss, `remember` `InvalidInput` for bad lengths |
| `http.byte_range(request, length)` with `found` and `satisfiable` | `http.byte_range(&status, request, length)`: `NotFound` means send the whole body, `InvalidInput` means 416 |
| `sort.search(values, x).index`, `.found` | `sort.search(values, x)`, the index or `len(values)` on a miss |
| `flags.Value.found` | `value.occurrences > 0` |
| `pcre2.capture(data, i)`, `cgltf.attribute`/`indices`/`material`/`node_mesh`, `box2d.contact`, layout `cluster_at`/`at_point` with `.found` | Each takes `&status` first and returns the plain value; a miss records `NotFound` (layout: `InvalidInput`) |
| `sqlite.step(&s)` returning a `StepResult` | `sqlite.step(&status, &s)` returning the `State` |
| `sqlite.constraint(statement)` | `sqlite.constraint(&status.failure)` |
| A bare `nil` or `false` from a vendor call (SDL3, lua, curl, tree-sitter, ...) | the status; the call returns its value |
| Library loaders (`opengl.load`, ...) returning `missing` | `load(&status, loader)` failing with `NotFound` |

A failure that comes from bad input carries the byte offset where the input
went wrong (`failure.offset` when `failure.has_offset`).

### Iterators

`next`, `scan_*`, `read_line` and the other step-by-step readers return the
value itself. The `{value, found}` result structs (`Next`, `Scanned`,
`Piece`, `Component`, `Grapheme`, `NextPart`, `Popped`) are gone. The call
that finds nothing left sets `ended` on the state you passed, and returns
zero. A failure sets it too, so a loop stops either way:

```dyn
// Before
for {
  item := ini.next(&status, &scan)
  if !item.found { break }
  apply(item.value)
}

// After
for {
  item := ini.next(&status, &scan)
  if scan.ended { break }
  apply(item)
}
```

| Before | After |
| --- | --- |
| `x := next(...)`, `x.found`, `x.value` | `x := next(...)`, `state.ended`, `x` |
| `for next(&status, &state).found { count += 1 }` | `for { _ = next(&status, &state)` / `if state.ended { break }` / `count += 1 }` |
| `Next.offset` (cbor, msgpack, protobuf, der): where the value starts | `state.start` |
| `Next.offset` (tar, zip archives): the position after the entry | `state.offset` |
| `path.Component.offset` | `components.start` |
| `fs.DirectoryEntry.found` | `directory.ended` |
| `watch.next(...).found`, `.event` | the `Event`; `watcher.ended` when none is pending now |
| `array.pop(&a)` returning `Popped(T)`, `ring.pop(&r)` returning `Popped` | the value, zero when empty; check `#len(a.items)` or `ring.length(&r)` first |
| `regex.next(&iterator)` returning `Found` | the `Match`; `iterator.ended` once there are no more |
| `archive.next(&status, reader)` returning `Header{ entry, found }` | `archive.next(&status, &reader)` returning the `Entry`; `reader.ended` at the end. `read`, `destroy_owned` and `error_message` take `&reader` |
| `bufio.read_line(&status, &reader, buffer)` returning a `ReadResult` | `line := bufio.read_line(&status, &reader)`, borrowing the reader's storage until the next read; `reader.ended` at the end. A line longer than the storage fails with `Capacity`. `read_until` keeps the buffer form |

### HTTP handlers

A handler is `fn(*fail.Status, *Response, *const Request)` and returns
nothing. Pass the status to every call. If the handler fails before it
responds, the server answers `500 internal server error` and logs the
failure, so a handler never answers its own failures:

```dyn
// Before
fn show(response: *http.Response, request: *const http.Request) http.Result {
  return http.respond(response, "hello", http.ResponseOptions{})
}

// After
fn show(status: *fail.Status, response: *http.Response, request: *const http.Request) {
  http.text(status, response, 200, "hello")
}
```

Also changed:

- `std/net/http/concurrent` and the exact-path `http.Router` are gone. Use
  `std/net/http/evented` and `http.Routes(T)` (`typed_routes`, `add`,
  `bind_routes`).
- `http.serve_stream` takes the context argument that
  `serve_stream_context` took.
- `config.http2 = true` and `config.http3 = true` become `config.http2 =
  evented.http2()` and `config.http3 = evented.http3()`; left unset, their
  code is not linked.
- `ResponseOptions.cookies` takes `http.Cookie` values.
- `http.redirect` takes cookies instead of formatted text.

## 4. Arenas

Running out of an arena now always panics, fixed buffers included. Size
the arena for the work. The `try_` forms and their error kinds are gone.

| Before | After |
| --- | --- |
| `arena_push`, `arena_push_array` | `mem.push(T, arena)`, `mem.push_array(T, arena, count)` |
| `push_bytes_uninit`, `arena_push_uninit` | `mem.push_bytes(arena, count)` (byte-aligned) |
| `try_push`, `try_push_array`, `arena_try_push*`, `ErrorKind` | the plain push |
| `arena_alloc_bounded(block, limit)` | `source := mem.pages(limit)`, `source.block_size = block`, `mem.arena_from_source(source)` |
| `arena_sub(parent, size)` | `mem.arena_from_source(mem.within(parent, size))` |
| `arena_remaining` | `mem.arena_room` |
| `arena_snapshot`, `arena_capacity`, `peak_used` | `mem.arena_used` |
| `arena_start(arena)` | `mem.ArenaHeader` |
| `append`, `append_grow`, `arena_try_extend` | `std/container/array` or `std/bytes/builder` |
| `scratch_begin`/`scratch_end` | `mark := mem.arena_mark(scratch)` and `defer mem.arena_rewind(scratch, mark)` |

`fs.read_all` no longer fails with `Capacity`. A file larger than the arena
can hold panics.

## 5. Language

| Before | After |
| --- | --- |
| `outer: for ...` with `break: outer` | Set a flag and break again, or move the inner loop into a function |
| `for *const x in xs` | `for *x in xs`. Over a const slice it binds `*const` (`dyn fix` does this) |
| `#offset(p, i)` | `#slice(p, count)[i]` |
| An integer or text `case` made exhaustive by ranges | Add a `_` arm |
| Cleanup in a `defer` that must run at a crash | `panic.set_handler`. A panic no longer runs defers |
| `return` or `#panic` after an endless `for {}` | Optional now. An endless `for` with no `break` ends the function |

Two rules change meaning without an error. Review them where they apply:

- **Target-typed arithmetic.** `total: u64 = a_u32 * b_u32` now multiplies in
  `u64`. Where 32-bit wrapping is meant, give the narrow type:
  `hashed: u32 = value * 2654435761`.
- **Signed/unsigned comparison by value.** `-1 < len` is now true for a
  `usize` `len`. Comparisons that relied on the old conversion change
  result.

`--check-overflow` now checks std and vendor code too. Where arithmetic
means to wrap, as in hashes, rotations and SWAR, write `#wrapping(expr)`.

## 6. Counts and sizes are `usize`

Public counts, lengths, sizes and indexes are `usize` throughout std and the
vendor wrappers:

- sqlite parameter and column indexes, and `column_count`
- `pcre2.capture`
- tree-sitter `child`, `child_count`, `node_start` and `node_end`
- `lua.pop` and `stack_size`
- stb image and atlas sizes
- image `width`/`height`, and font sizes

Drop the `#cast(i32, ...)` around arguments. Where you stored a result in an
`i32`, store it in a `usize`.

## 7. Smaller items

- `vendor/openssl/tls`: `quic_read` and `quic_write` take the status and
  return a `QuicAttempt { count, blocked, ended }`. `QuicStatus` and `QuicIo`
  are gone from the vendor module, and `evented.QuicStatus` drops `Reset`.
- `fs.make_directory(&status, path, mode)` drops the mode and makes the
  directory 0o755. For other bits, call `fs.make_directory_mode(&status,
  path, mode)`.
- `bytes.Builder` is gone. Use `std/bytes/builder`.
- Matrix and quaternion functions return plain values. Degenerate input
  gives the zero value.
- `fmt.buffer`, `html.writer` and `json.writer` take a status in place of
  their own `failed` flag.

[std index](../guide/std-index.md) has every current signature.
