# Standardization, 2026-11-13

This change removes duplicate spellings, drops two rules that each needed their
own exceptions, and adds two forms that daily code kept working around. Most old
code fails to compile with an error that names the fix.

Run `tools/migrate-standard.py DIR...` first. It removes the redundant `= []`
from declarations and makes the std renames below, following each module's
import aliases. Pass `--embedded` to rewrite Dyn code inside Python test
strings and Markdown too.

| Old | New |
| --- | --- |
| `p: Point = .{ x: 1 }` | `p := Point{ x: 1 }` |
| `return .{}` | `return Result{}`, naming the type |
| `buffer: [64]u8 = []` | `buffer: [64]u8` |
| `#cast(Color, n)` | `enums.from_int(Color, n)` |
| `0 <= i < n` | `0 <= i && i < n` |
| `if ready { x := parse(x) }` | `if ready { parsed := parse(x) }` |
| `#bitcast(*T, pointer)` | `#cast(*T, pointer)` |
| `for i in 0..#len(xs) { x := xs[i] ... }` | `for x, i in xs { ... }` (optional) |
| `if bytes.equal(s, "a") {...} else if ...` | `case s { "a" => {...} _ => {...} }` (optional) |
| `--check-overflow` | the default for debug builds; `--no-check-overflow` turns it off |
| `mem.arena_create(size)` | `mem.arena_alloc(size)` (also `_bounded`, `arena_try_alloc*`) |
| `mem.ArenaCreation` | `mem.ArenaAllocation` |
| `json.make_object(arena)` and the other `make_*` | `json.push_object(arena)`, `push_*` |
| `box.create(arena, ...)` | `box.push_state(arena, ...)` |
| `strings.equal`, `find*`, `contains`, `starts_with`, `ends_with` | the same names in `std/bytes` |
| `testing.equal_bytes(a, b)` | `bytes.equal(a, b)` |
| `_ = fmt.write(&buffer, text)` | `fmt.write(&buffer, text)`, then check `buffer.failed` once |
| `if !html.write_escaped(&buffer, text)` | `html.write_escaped(&buffer, text)`, then `buffer.failed` |
| `t.status == io.Status.Error` | `io.failed(t.failure)` |
| `t.kind`, `t.error` on `io.Transfer` | `t.failure.kind`, `t.failure.native` |
| `t.status == io.Status.Complete` meaning success | `io.complete(t)` |
| `bufio.ReadStatus.Error`, `watch.Status.Error` | `io.failed(result.failure)` |
| hand-rolled sort for structs | `sort.sort_by(values, less)`, `sort.stable_by(arena, values, less)` |

## Compiles, but check

- Debug builds now panic with `overflow.ok` where the program's own `+ - * <<`
  or negation overflows. Code that means to wrap, such as hashes and random
  number generators, should call `math.wrapping_add`, `wrapping_sub` or
  `wrapping_mul`. `std` and `vendor` code keeps wrapping, and release builds
  always wrap.
- `enums.from_int` gives the first variant for a tag that names no variant,
  where `#cast` used to keep the unknown tag until a `case` panicked on it.
- A struct or plain enum passed by name to a literal template now prints its
  contents, `Unit{name: ada, at: Vec2{x: 1.5, y: 2}}`, where it used to print
  nothing. Enums with set tags print the tag.
- A literal format template is checked against its arguments when it compiles.
  A template built at run time that does not match its arguments now prints
  anyway: a missing value prints `{?}`, an extra one prints at the end as
  `{+value}`, and a value with no text form prints `{?}`. `print_to` and
  `println_to` still report `InvalidInput`, and `strings.format` no longer
  panics.
