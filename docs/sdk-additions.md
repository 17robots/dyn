# SDK additions, September 2026

## Processes

`std/process` provides `spawn`, `wait`, `terminate`, `pipe`, `close_pipe`,
`environment`, and bounded `capture`, backed by Linux, Darwin and Windows adapters.
Start with `process.options()` to inherit standard streams. Arguments include
argv[0]; executable paths are explicit, without a shell or PATH search. Child
environments are explicit `NAME=value` slices, empty by default. Retrieve selected
parent values with `environment` and pass what the child needs.

`spawn` uses temporary caller-arena storage and restores its mark before returning.
It rejects embedded NUL and reports executable/redirection failures. Linux/macOS
prepare strings before fork and use a close-on-exec error pipe; redirected sources
are duplicated before remapping to support swapped standard descriptors. Windows
uses UTF-16 CreateProcessW, CRT argument quoting, sorted environment entries and an
explicit inherited-handle list. Programs with custom command-line parsers may need
their own quoting adapter. Darwin's libSystem link is declared by the module and
resolved through the target SDK.

`capture` drains stdout and stderr fairly, checks exact caller capacity, and
terminates/reaps its direct child on timeout/overflow. It does not terminate a
process tree. Negative timeout means unlimited. A captured nonzero exit code is
not a wrapper failure; inspect `exit`. Native error numbers differ by platform.
Keep one owning Child slot; wait clears it after reaping. Pipe ends require close.
The exported pipe read end is intended for nonblocking capture; writes retain
ordinary blocking behavior. Windows uses PeekNamedPipe before reads.

## Filesystem watching and temporary directories

`std/fs/watch` currently targets Linux inotify. Watches are non-recursive;
register each directory. Events expose native mask, watch ID, move cookie and a
borrowed filename. `Empty` means drained, not closed. Queue overflow emits a rescan
event and sets sticky `rescan_required`. Rebuild the snapshot and reconcile queued
events before acknowledging it. No claim of lossless delivery or rename pairing.

`testing.temporary_directory(destination, prefix)` exclusively creates a private
0700 directory. `remove_temporary` takes caller-owned `fs.RemovalFrame` and byte
scratch slices; defer it in the creating scope. The underlying `fs.remove_tree`
uses descriptor-relative traversal, never follows symlinks, and returns capacity
errors at caller-selected depth. It may partially remove a tree before an error;
concurrent mutation can require retry. Scratch needs at least 280 bytes per frame.

## Unicode text

`std/unicode/text` pins Unicode **17.0.0**. It provides general category, combining
class, XID identifier properties, whitespace, full default case folding, all four
normalization forms, and extended grapheme iteration. This does not change the
language's identifier grammar or implement locale-specific casing/collation.

Normalization uses caller `[]u32` work split into two equal halves, each sized for
the fully decomposed scalar sequence. Output is caller `[]u8`. Overlapping input, output, or work is rejected before writing. Other failures
report invalid UTF-8 or capacity and may modify storage; `written` counts only
complete UTF-8 output scalars. Folding
is locale-independent and does not implicitly normalize. Grapheme slices borrow
input; invalid UTF-8 is sticky, and End is `ok=false, error=None`.

Tables are generated by `python3 tools/unicode/generate.py UCD.zip`, with an
embedded SHA-256 check against the official Unicode 17 archive. The data license
ships beside the generated file. `tests/unicode-conformance.py` runs the complete
published normalization, folding and grapheme vectors in debug and release.
Sources: [Unicode 17 UCD](https://www.unicode.org/Public/17.0.0/ucd/),
[UAX #15](https://www.unicode.org/reports/tr15/),
[UAX #29](https://www.unicode.org/reports/tr29/tr29-47.html).

## Property tests

`testing.check_property(options, work, predicate, context)` generates reproducible
byte slices from seed/iteration, then shrinks failures by deletion and byte-value
reduction. Work is split between sample and trial, so half its length is the
maximum generated input. The callback must be deterministic and cannot retain its
input. A minimized failure borrows work; `shrink_exhausted` reports budget limits.
The shrinker improves a failure; it does not promise a globally smallest input.

## Vendor additions

SQLite now exposes bounded busy timeout, 64-bit changes/last-row-ID results,
transaction begin/commit/rollback, and transaction state. Failed commit can leave
a transaction active; inspect state and retry or roll back. Other provider
interfaces retain their existing scope. See [allocation policy](vendor-allocation-policy.md)
for native heap ownership and binding-validation limits.

## Archive and XML interfaces

ZIP's `open_checked` validates directory/local-header relationships and supports
ZIP32 data descriptors. `extract` checks CRC and exact compressed consumption.
The low-level local-entry/stream reader remains available with its narrower
contract. Format reference: [PKWARE APPNOTE](https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXT).

TAR iteration is now stateful: `reader(source)` then `next(&reader)`. That state
retains global PAX defaults and applies local PAX/GNU long-name metadata to the
next real entry. `stream_reader(input, header, metadata)` takes caller `[]u8`
metadata storage (stack or an arena allocation), split into two equal banks.
Each half must fit the live global/local path and link names plus the next
extension payload. Metadata is compacted after every extension and reused across
entries, so memory does not grow with archive length. Empty metadata supports
plain entries only; insufficient storage returns sticky `-28`. Header and metadata
must be disjoint; overlap returns `-22` before reading. All returned names borrow
reader storage until the next `next_stream` call. Base-256 numbers and sparse extraction remain unsupported.

XML scanners and writers share Unicode name checks from
[XML 1.0 Fifth Edition](https://www.w3.org/TR/xml/). For namespace-aware processing,
create `namespaces(bindings, frames, storage)`, enter Start events, resolve
attribute names, and leave End events. Self-closing elements enter and leave in
one caller iteration. The context copies scope names/URIs into caller storage,
normalizes namespace attribute references, restores shadowed bindings on leave,
and rejects duplicate expanded attribute names. Syntax/document validation stays
separate from namespace context management. Rules follow
[Namespaces in XML 1.0](https://www.w3.org/TR/xml-names/).

## Storage and failure contracts

- Caller buffers can be stack storage or slices allocated through `std/mem`.
  No new Dyn heap allocation is introduced by these interfaces.
- Unicode transforms reject input/output/work overlap with `ErrorKind.Overlap`
  before writing. A later error may leave a complete UTF-8 prefix (`written`).
  Normalization validates/decomposes into work first, so work exhaustion or invalid
  input leaves output unchanged, but work may be modified.
- ZIP extraction rejects destination/payload overlap before writing. Capacity and
  shape preflight failures write nothing. Malformed DEFLATE or CRC failure may
  modify output, but return no successful `data`. Stream header/name/payload
  buffers must be disjoint; overlap is a sticky `Overlap` error before input reads.
- TAR stream capacity (`-28`), overlap (`-22`), malformed input (`-74`), and source
  I/O errors are sticky. Partial input consumption on failure is possible. Retrying
  the same failed reader performs no I/O; create a new reader to restart.
- Namespace `enter` rejects event-name/attribute overlap with context byte storage
  before writing. Capacity/syntax failure restores logical depth/count/used;
  unused storage slots may have changed. Existing live bindings remain valid.
  Capacity preflight uses raw URI byte length as an upper bound before entity
  normalization; reserve element-name, prefix, and raw URI bytes for each scope.
  A resolved element name borrows context storage until scope exit; attribute
  local names returned by `resolve` borrow the argument passed to it. Binding,
  frame, and byte buffers must themselves be disjoint and valid for the context.
- Process capture rejects overlapping stdout/stderr buffers with `-22` before
  creating pipes or a child. Output slices borrow those buffers and retain captured
  prefixes on timeout/overflow/read failure. Arena scratch must be disjoint from
  all arguments, environment strings, and output buffers; spawn restores its mark.
- Property-test examples borrow work until reused. Replay requires the same seed,
  iteration, work capacity, and deterministic predicate; shrinking has a bounded
  check budget, not a global-minimum guarantee.
