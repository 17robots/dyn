# The layer of every std module; tests/std-layers.py checks it.
#
# core  No operating system and no memory source. Builds for every target,
#       bare metal included, and imports only core.
# heap  Takes arenas from std/mem. Builds for every target, bare metal
#       included, and imports only core and heap.
# std   Needs an operating system: files, sockets, processes, threads, clocks,
#       or the raw system bindings in std/os.
#
# Imports in files for a particular operating system (#target(kernel: linux),
# for example) do not count: bare-metal builds never compile them.
